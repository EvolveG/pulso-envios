# Pulso · Envio de Links

Página web do RH (Grupo JFS) para enviar aos colaboradores os links da Pesquisa de Satisfação, por WhatsApp ou email.

- Abrir: `index.html` (ou `envios.html`) no GitHub Pages.
- O ficheiro Excel é lido apenas no navegador de quem usa a página; nenhum dado de colaboradores é guardado neste repositório.
- A memória de envios e as definições ficam guardadas no navegador de cada máquina.
